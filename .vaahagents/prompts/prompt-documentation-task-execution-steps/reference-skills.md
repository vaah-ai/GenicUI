# Skills — Invoke When Relevant

| Skill | Invoke when |
|---|---|
| `nuxt` | Editing `nuxt.config.ts`, layers, modules, or Nuxt 4 wiring |
| `nuxt-content` | Authoring markdown, configuring collections, `queryCollection()` |
| `nuxt-seo` | `llms.txt`, sitemap, OG metadata, `Accept: text/markdown` routing |
| `nuxt4-patterns` | Any Nuxt 4–specific API (app/ dir, server/, islands) |
| `tailwind-css-patterns` | Tailwind utility patterns inside MDC or components |
| `tailwind-design-system` | Building a design system / theme tokens |
| `vercel:deploy` / `vercel:env` / `vercel:deployments-cicd` | M5.1-T12 only |
| `web-perf` | Before claiming Lighthouse ≥ 90 — run a perf audit |
| `code-review` | Optional — review the doc diff before committing |
| `brainstorming` | When the IA choice or section scope is genuinely ambiguous |

**Rule:** Invoke the skill BEFORE writing code for that area. The skill output guides your work; don't ignore it.
