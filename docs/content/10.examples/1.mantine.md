## Why a second library?

The shipped [PrimeVue Registry](/api/primevue-registry) proves one Vue-based library can be wrapped, but a single example doesn't establish a pattern. **GenicUI is library-agnostic** by design (see [Components](/concepts/components)), and Mantine is the canonical second example: a React runtime package (`@mantine/core`), typed-prop API that maps 1-to-1 to the wrapper pattern, and high dev-community signal (Linear, Raycast, Vercel). This page walks the same four-step recipe in [Custom Registry](/guides/custom-registry), applied to Mantine's `<Button>`, `<TextInput>`, and `<Modal>`.

## The 4-step adapter recipe

Every third-party library wraps into GenicUI via the same four steps. The recipe is library-agnostic — Mantine, shadcn, MUI, or your in-house design system all follow it.

::steps{level="3"}
#### Extend `GenicElement`

Import the base class from `@genicui/client`. Subclass and override `render(props)` to mount the underlying library component inside the closed Shadow DOM.

#### Use the closed Shadow DOM

The base class calls `attachShadow({ mode: 'closed' })` in `connectedCallback` (F21-AC1). Library styles cannot bleed out; page styles cannot bleed in.

#### Declare `propsSchema` with `additionalProperties: false`

The TypeBox schema is the trust boundary — the server-side catalog rejects any prop not enumerated.

#### Register with `customElements.define`

Call `customElements.define('genui-mantine-button', MantineButton)` at module load. Element names follow the `genui-<library>-<component>` convention used by the PrimeVue registry.
::

::callout{type="warning"}
**Never re-open the Shadow Root.** Components that access `element.shadowRoot` from outside the runtime break F21. The base class holds the only closed reference; the runtime is the only path in.
::

## Wrap `<Button>`

`<Button>` is the simplest case — no internal state, no events beyond `click`. Mantine's typed props (`variant`, `size`, `disabled`, `loading`) map directly to a TypeBox schema.

```tsx [src/elements/mantine-button.tsx]
import { Type } from '@sinclair/typebox';
import { GenicElement } from '@genicui/client';
import { Button } from '@mantine/core';

export const MantineButtonProps = Type.Object({
  label: Type.String(),
  variant: Type.Optional(Type.Union([
    Type.Literal('filled'),
    Type.Literal('outline'),
    Type.Literal('subtle'),
    Type.Literal('light'),
    Type.Literal('default'),
  ])),
  size: Type.Optional(Type.Union([
    Type.Literal('xs'),
    Type.Literal('sm'),
    Type.Literal('md'),
    Type.Literal('lg'),
    Type.Literal('xl'),
  ])),
  disabled: Type.Optional(Type.Boolean()),
  loading: Type.Optional(Type.Boolean()),
}, { additionalProperties: false });

export class MantineButton extends GenicElement {
  protected render(props: Record<string, unknown>): void {
    if (!this._shadowRoot) return;
    const root = document.createElement('div');
    this._shadowRoot.appendChild(root);
    // Mantine's CSS variables live on :root — copy them into the shadow
    this._shadowRoot.adoptedStyleSheets = [...document.adoptedStyleSheets];

    import('react-dom/client').then(({ createRoot }) => {
      createRoot(root).render(
        <Button
          variant={(props.variant as string) ?? 'filled'}
          size={(props.size as string) ?? 'md'}
          disabled={Boolean(props.disabled)}
          loading={Boolean(props.loading)}
        >
          {props.label as string}
        </Button>,
      );
    });
  }
}

customElements.define('genui-mantine-button', MantineButton);
```

## Wrap `<TextInput>`

`<TextInput>` introduces controlled-input plumbing. Mantine's `onChange` fires `event.currentTarget.value`; the GenicUI bridge expects `{ value }` in the event payload.

```tsx [src/elements/mantine-text-input.tsx]
import { Type } from '@sinclair/typebox';
import { GenicElement } from '@genicui/client';
import { TextInput } from '@mantine/core';

export const MantineTextInputProps = Type.Object({
  label: Type.String(),
  placeholder: Type.Optional(Type.String()),
  value: Type.Optional(Type.String()),
}, { additionalProperties: false });

export class MantineTextInput extends GenicElement {
  protected render(props: Record<string, unknown>): void {
    if (!this._shadowRoot) return;
    const root = document.createElement('div');
    this._shadowRoot.appendChild(root);
    this._shadowRoot.adoptedStyleSheets = [...document.adoptedStyleSheets];

    // Re-emit onChange as a composed CustomEvent so the runtime bridge forwards it.
    const handleChange = (event: React.ChangeEvent<HTMLInputElement>) => {
      this.dispatchEvent(new CustomEvent('change', {
        detail: { value: event.currentTarget.value },
        bubbles: true,
        composed: true,   // crosses the closed Shadow DOM boundary
      }));
    };

    import('react-dom/client').then(({ createRoot }) => {
      createRoot(root).render(
        <TextInput
          label={props.label as string}
          placeholder={props.placeholder as string | undefined}
          value={(props.value as string) ?? ''}
          onChange={handleChange}
        />,
      );
    });
  }
}

customElements.define('genui-mantine-text-input', MantineTextInput);
```

## Wrap `<Modal>`

`<Modal>` adds internal state (open/close) and focus trapping. Mantine's controlled API (`opened`, `onClose`, `title`) maps cleanly.

```tsx [src/elements/mantine-modal.tsx]
import { Type } from '@sinclair/typebox';
import { GenicElement } from '@genicui/client';
import { Modal } from '@mantine/core';

export const MantineModalProps = Type.Object({
  title: Type.String(),
  opened: Type.Boolean(),
  centered: Type.Optional(Type.Boolean()),
  radius: Type.Optional(Type.String()),
}, { additionalProperties: false });

export class MantineModal extends GenicElement {
  protected render(props: Record<string, unknown>): void {
    if (!this._shadowRoot) return;
    const root = document.createElement('div');
    this._shadowRoot.appendChild(root);
    this._shadowRoot.adoptedStyleSheets = [...document.adoptedStyleSheets];

    const handleClose = () => {
      // Composed: true so the agent receives `modal_close` and can re-render
      // with `opened: false` to keep the modal server-controlled.
      this.dispatchEvent(new CustomEvent('modal_close', {
        detail: { reason: 'user_dismissed' },
        bubbles: true,
        composed: true,
      }));
    };

    import('react-dom/client').then(({ createRoot }) => {
      createRoot(root).render(
        <Modal
          title={props.title as string}
          opened={Boolean(props.opened)}
          onClose={handleClose}
          centered={Boolean(props.centered)}
          radius={props.radius as string | undefined}
        >
          <p>Modal content goes here.</p>
        </Modal>,
      );
    });
  }
}

customElements.define('genui-mantine-modal', MantineModal);
```

The agent receives `modal_close` and can respond with a fresh `render_component` setting `opened: false` — the same `composed: true` round-trip as PrimeVue's `input-pair` → `result-card` (see [Custom Events](/cookbook/custom-event)).

## Registry.json entry

The server reads a `registry.json` companion to load entries into the catalog at boot.

```json [registry.json (excerpt)]
{
  "id": "@genicul-mantine/registry",
  "version": "0.1.0",
  "framework": "mantine@7.0.0",
  "trustTier": "project",
  "components": [
    {
      "name": "mantine-button",
      "version": "1.0.0",
      "uri": "ui://components/mantine-button@1.0.0",
      "propsSchema": { "$ref": "./schemas/mantine-button.schema.json" },
      "tags": ["button", "action", "form", "mantine"]
    },
    {
      "name": "mantine-modal",
      "version": "1.0.0",
      "uri": "ui://components/mantine-modal@1.0.0",
      "propsSchema": { "$ref": "./schemas/mantine-modal.schema.json" },
      "tags": ["modal", "dialog", "overlay", "mantine"]
    }
  ]
}
```

The trust tier defaults to `project` (see [Trust Boundary](/concepts/trust-boundary#trust-tiers) for the other two tiers).

## What's out of MVP scope

This walkthrough intentionally does **not** ship:

- **A real `@genicul-mantine/registry` package.** See F34 in the post-MVP backlog.
- **A React 18+ server runtime.** `render_component` returns `STATE_SNAPSHOT`; the React tree mounts in the closed shadow DOM via `react-dom/client`. SSR is not in scope.
