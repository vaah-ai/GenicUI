A single WebSocket carries up to 256 channels — one per mounted component plus the three reserved system channels. When you need components to talk to each other (master → child, dashboard tiles syncing, multi-pane forms), use the `__broadcast__` channel as the coordination layer and a per-component channel for state.

## Problem

You're rendering a dashboard with three tiles — a master filter, a summary card, and a detail table. When the user changes a filter on the master, the other two must update atomically. Each component already has its own channel for `STATE_SNAPSHOT`/`STATE_DELTA`. How do they coordinate without a separate RPC?

## Solution

Reserve `__broadcast__` (one of the three reserved channels) for cross-component coordination events. Components subscribe to `__broadcast__` and react to typed coordination frames. Each component's own channel still carries its `STATE_DELTA` — `__broadcast__` carries only the *coordination intent*, not the state.

::callout{type="warning"}
The three reserved channels — `__session__`, `__mcp__`, `__agent__` — are checked at mount time ([Frames › Channel model](/concepts/frames#channel-model)). Reusing them as component channels returns `-32008 surface_unavailable`. `__broadcast__` is the *fourth* implicit reserved channel for cross-component events.
::

## Code

```ts [src/genui/components/dashboard-master.ts]
import { GenicElement } from '@genicui/client';
import { envelope } from '@genicui/core';

export class DashboardMaster extends GenicElement {
  static events = {
    filter_changed: /* schema */ undefined as never,
  };

  // The runtime injects a bridge with .send(channel, frame)
  private bridge = GenicElement.getRuntimeBridge();

  private onFilterChange = (e: Event) => {
    const value = (e.target as HTMLInputElement).value;
    // 1. Update own state via normal STATE_DELTA path
    this.dispatchEvent(new CustomEvent('filter_changed', {
      detail: { value }, bubbles: true, composed: true,
    }));

    // 2. Coordinate with siblings via __broadcast__
    this.bridge.send('__broadcast__', envelope(
      'COORDINATION',
      {
        kind: 'filter.changed',
        source: this.componentId,
        payload: { value },
      },
      '__broadcast__',
    ));
  };

  connectedCallback() {
    super.connectedCallback();
    this.addEventListener('change', this.onFilterChange);
  }
}

customElements.define('genui-dashboard-master', DashboardMaster);
```

Child components subscribe to `__broadcast__` and apply the coordination:

```ts [src/genui/components/dashboard-detail.ts]
import { GenicElement } from '@genicui/client';

export class DashboardDetail extends GenicElement {
  connectedCallback() {
    super.connectedCallback();
    GenicElement.getRuntimeBridge().onEvent((evt) => {
      if (evt.kind === 'COORDINATION' && evt.detail?.kind === 'filter.changed') {
        // Apply the filter to own state — runtime will emit STATE_DELTA
        this.setAttribute(
          'props-json',
          JSON.stringify({ ...this.props, filter: evt.detail.payload.value }),
        );
      }
    });
  }
}

customElements.define('genui-dashboard-detail', DashboardDetail);
```

The agent observes the resulting frame sequence:

```text
__broadcast__: COORDINATION { kind: 'filter.changed', source: 'master-id' }
master channel:  STATE_DELTA { patch: [{op: 'replace', path: '/filter', value: 'active'}] }
detail channel:  STATE_DELTA { patch: [{op: 'replace', path: '/filter', value: 'active'}] }
summary channel: STATE_DELTA { patch: [{op: 'replace', path: '/count',   value: 42}] }
```

All four frames are causally consistent — the `__broadcast__` frame arrives before any sibling `STATE_DELTA`, so the agent's next tool call sees the post-filter state on every component.

## Pitfalls

- **256 channels per socket.** Hard cap — opening the 257th returns `-32001 component_not_found`. With 3 reserved system channels + `__broadcast__` you get 252 component channels in practice. If you need more, open a second socket.
- **Don't put state on `__broadcast__`.** Coordination events are *intents* — the actual state lives on each component's own channel. Putting props on `__broadcast__` creates a write race: two siblings updating `__broadcast__` simultaneously produce torn reads.
- **Backpressure on `__broadcast__` is global.** The 500-frame outbound cap ([Events › Backpressure](/concepts/events#backpressure-and-rate-limits)) is per-socket, not per-channel. A coordination storm on `__broadcast__` consumes the same budget as a chatty component. Throttle coordination events the same way you'd throttle any high-frequency frame.
- **`envelope()` validates the channel name.** Passing `__broadcast__` as the third arg to `envelope()` is allowed because it's reserved — the validator checks against `RESERVED_CHANNELS`. If you mistype (`__boradcast__`), you get a `GenicUIError` before the frame hits the wire. See [Core API › `validateChannel`](/api/core#validatechannelchannel).
- **Don't subscribe on every render.** Attach the `onEvent` listener in `connectedCallback` and remove it in `disconnectedCallback`. The runtime guarantees the bridge is the same instance per socket, so adding listeners per-render leaks.
- **Causality over `causes[]`.** When the master dispatches a coordination frame, set `causes: [lastSeq]` on the `STATE_DELTA` so the agent's run-tracer can rebuild the causal chain. See [Protocol › Frame envelope schema](/concepts/protocol#frame-envelope-schema).
