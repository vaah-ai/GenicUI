Out of the box, `GenicElement` propagates click-style events. But what about drag, hover, focus, swipe, and any other pointer mutation you want to send to the agent? This recipe adds a custom event surface — emit it correctly, debounce the noise, and bound the payload.

## Problem

You want to track rich pointer state on a `<genic-data-table>` row — `drag_started`, `drag_ended`, `hover_changed`, `focus_changed` — not just `row_selected`. The default `row_selected` event fires once per click; a drag-tracked UI fires hundreds of `drag_over` events per second.

## Solution

Subclass `GenicElement`, attach pointer listeners, dispatch `CustomEvent` with `composed: true` so it crosses the closed Shadow DOM, declare each new event in `static events` with a TypeBox `payloadSchema`, and debounce the high-frequency ones at the source.

::callout{type="warning"}
Events without `composed: true` are silently dropped at the Shadow boundary — see [Events › The composed: true decision](/concepts/events#the-composed-true-decision). F19-AC1 enforces this.
::

## Code

```ts [src/genui/components/drag-row-table.ts]
import { GenicElement } from '@genicui/client';
import { Type, type Static } from '@sinclair/typebox';

const DragRowEvents = {
  drag_started: Type.Object({
    rowId: Type.String(),
    x: Type.Number(),
    y: Type.Number(),
  }, { additionalProperties: false }),

  drag_ended: Type.Object({
    rowId: Type.String(),
    droppedOn: Type.Union([Type.String(), Type.Null()]),
  }, { additionalProperties: false }),

  hover_changed: Type.Object({
    rowId: Type.Union([Type.String(), Type.Null()]),
  }, { additionalProperties: false }),

  focus_changed: Type.Object({
    rowId: Type.String(),
    focused: Type.Boolean(),
  }, { additionalProperties: false }),
};

type DragRowEvents = Static<typeof DragRowEvents>;

export class DragRowTable extends GenicElement {
  static events = DragRowEvents;

  connectedCallback() {
    super.connectedCallback();
    this.addEventListener('pointerdown', this.onDown);
    this.addEventListener('pointermove', this.onMove);
    this.addEventListener('pointerup', this.onUp);
    this.addEventListener('pointerenter', this.onEnter);
    this.addEventListener('pointerleave', this.onLeave);
  }

  disconnectedCallback() {
    super.disconnectedCallback();
    this.removeEventListener('pointerdown', this.onDown);
    this.removeEventListener('pointermove', this.onMove);
    this.removeEventListener('pointerup', this.onUp);
    this.removeEventListener('pointerenter', this.onEnter);
    this.removeEventListener('pointerleave', this.onLeave);
  }

  // Debounce hover events — 200ms coalesce window
  private hoverTimer: ReturnType<typeof setTimeout> | null = null;
  private emitHover(rowId: string | null) {
    if (this.hoverTimer) clearTimeout(this.hoverTimer);
    this.hoverTimer = setTimeout(() => {
      this.dispatchEvent(new CustomEvent('hover_changed', {
        detail: { rowId },
        bubbles: true,
        composed: true,
      }));
    }, 200);
  }

  private onDown = (e: PointerEvent) => {
    const row = (e.target as HTMLElement).closest('[data-row-id]');
    if (!row) return;
    const rowId = row.getAttribute('data-row-id')!;
    this.dispatchEvent(new CustomEvent('drag_started', {
      detail: { rowId, x: e.clientX, y: e.clientY },
      bubbles: true, composed: true,
    }));
  };

  private onMove = (e: PointerEvent) => {
    // pointermove fires 100s/sec — debounce or batch
    this.emitHover((e.target as HTMLElement).closest('[data-row-id]')?.getAttribute('data-row-id') ?? null);
  };

  private onUp = (e: PointerEvent) => {
    const row = (e.target as HTMLElement).closest('[data-row-id]');
    const droppedOn = row?.getAttribute('data-row-id') ?? null;
    this.dispatchEvent(new CustomEvent('drag_ended', {
      detail: { rowId: droppedOn ?? 'unknown', droppedOn },
      bubbles: true, composed: true,
    }));
  };

  private onEnter = (e: PointerEvent) =>
    this.emitHover((e.target as HTMLElement).closest('[data-row-id]')?.getAttribute('data-row-id') ?? null);

  private onLeave = () => this.emitHover(null);
}

customElements.define('genui-drag-row-table', DragRowTable);
```

## Verification

```bash
# 1. Mount the component
curl -X POST http://localhost:3040/mcp \
  -H "Authorization: Bearer $GENICUI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":"1","method":"tools/call","params":{"name":"render_component","arguments":{"name":"DragRowTable","props":{"rows":[{"id":"r1"},{"id":"r2"}]}}}}'
# → returns componentId, e.g. drt-sess9f8e-01HK9X

# 2. Subscribe to the new events
curl -X POST http://localhost:3040/mcp \
  -H "Authorization: Bearer $GENICUI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":"2","method":"tools/call","params":{"name":"subscribe_to_events","arguments":{"componentId":"drt-sess9f8e-01HK9X","actions":["drag_started","drag_ended","hover_changed"]}}}'

# 3. Open the playground and drag a row across the table.
# The WebSocket on the server emits (in order):
#   drag_started  { rowId: "r1", x: 142, y: 318 }
#   hover_changed { rowId: "r2" }            ← only after 200ms quiet
#   drag_ended    { rowId: "r2", droppedOn: "r2" }
```

The verification proves three things: the events cross the Shadow boundary (`composed: true`), the server's `payloadSchema` validation accepts them, and the 200ms debounce coalesces the pointermove storm into a single wire frame.

## Pitfalls

- **Debounce at the source.** Server-side throttling caps at 200 events/sec per component ([Events › Backpressure](/concepts/events#backpressure-and-rate-limits)) — drag fires faster than that. If you don't debounce, the server drops the tail of the stream and `drop_count` ticks up silently.
- **Bound the payload.** A `drag_started` event with the full row tree (`detail: { row }`) couples your schema to your UI tree. Send only the `rowId` — let the agent `update_component` to fetch the row's current state if it needs more.
- **Don't dispatch `focus_changed` on every focus movement.** Browser focus events fire on tab, on click, on programmatic `element.focus()` — your agent will see noise. Emit on `blur` of the *previous* element + `focus` of the new one, or skip `focus_changed` entirely and let the agent rely on `selection`.
- **`composed: true` is non-negotiable.** See the callout above — events without it never leave the Shadow DOM. The runtime's event bridge listens at `document` with `{ capture: true }`; without the flag, the event stops at the Shadow Root.
- **Validate `payloadSchema`.** Each entry in `static events` is read by the trust boundary when the server validates the inbound event. An undeclared event name returns a warning and increments `drop_count`. Add every event you emit.
- **Cleanup listeners on `disconnectedCallback`.** Pointer listeners attached in `connectedCallback` leak if not removed. The example above pairs each `addEventListener` with a matching `removeEventListener`.
