A full agent turn is render → update → event. Mocking all three is tempting — but mocking the trust boundary lets bugs through. This recipe runs the **real server** against an in-memory session and a stubbed LLM, then drives the Web Component half with Playwright. You get fast tests that catch what mocks miss.

## Problem

You want to assert that "clicking row #2 in `DataTable` emits a `row_selected` event with `{ rowId: '2' }` and the agent's next tool call is `update_component`." That's a render-update-event round trip. Pure unit tests can't see the WebSocket frames; full e2e with a real LLM is slow and flaky.

## Solution

Split the loop in two:

1. **Server half** (`agent → server → component`) — run the real GenicUI server against an `InMemoryStore`, use a stub LLM that returns a fixed tool-call sequence. Tests are deterministic and run in <500ms.
2. **Browser half** (`component → DOM → user`) — drive Playwright against `examples/playground/`, click rows, assert DOM mutations and outbound `CustomEvent`s.

::callout{type="info"}
The pattern below mirrors `examples/testing-cookbook/` — see [Testing › The pyramid](/guides/testing#the-pyramid) for the 150/20/3-5 split and where e2e sits.
::

## Code

Server half — in-process server with a stub LLM:

```ts [tests/integration/full-loop.test.ts]
import { test, expect } from 'bun:test';
import { createServer } from '@genicui/server';
import { InMemoryStore } from '@genicui/core';
import type { AgentBridge, LLMProvider } from '@genicui/agent-bridge';

// Stub LLM that returns a fixed tool-call sequence
const stubLLM: LLMProvider = {
  async chat(messages, tools) {
    return {
      choices: [{
        message: {
          role: 'assistant',
          tool_calls: [{
            id: 'tc-1',
            type: 'function',
            function: {
              name: 'render_component',
              arguments: JSON.stringify({
                name: 'DataTable',
                props: { rows: [{ id: '1' }, { id: '2' }], columns: [{ key: 'id', label: 'ID' }] },
              }),
            },
          }],
        },
      }],
    };
  },
};

test('agent renders DataTable, user clicks row #2, agent receives row_selected', async () => {
  // 1. Spin up the real server on an ephemeral port
  const app = createServer();
  const port = 3041;
  const server = app.listen(port);

  try {
    // 2. Open a WebSocket + call the stubbed agent
    const ws = new WebSocket(`ws://localhost:${port}/ws`);
    await new Promise((r) => ws.addEventListener('open', r, { once: true }));
    const bridge = await AgentBridge.connect(stubLLM, `http://localhost:${port}/mcp`);

    // 3. Drive the agent — first call renders, second emits a deterministic reply
    const reply = await bridge.execute('Show me a table');
    expect(reply).toBeTruthy();

    // 4. Simulate the user clicking row #2 on the open WebSocket
    const sent: any[] = [];
    ws.addEventListener('message', (e) => sent.push(JSON.parse(e.data)));
    ws.send(JSON.stringify({
      v: 1, channel: 'dt-...', type: 'COMPONENT_EVENT',
      payload: { componentId: 'dt-...', action: 'row_selected', detail: { rowId: '2' } },
      seq: 1,
    }));

    // 5. Assert the server forwarded to the agent subscription
    await new Promise((r) => setTimeout(r, 50));
    expect(sent.some((f) => f.type === 'COMPONENT_EVENT' && f.payload?.detail?.rowId === '2'))
      .toBe(true);

    await bridge.close();
    ws.close();
  } finally {
    server.stop();
  }
});
```

Browser half — Playwright drives the Web Component:

```ts [e2e/click-row.spec.ts]
import { test, expect } from '@playwright/test';

test('clicking a DataTable row dispatches row_selected with the row id', async ({ page }) => {
  await page.goto('http://localhost:3042/');

  // Mount via MCP first (or use the playground's dev shortcut that mounts on load)
  await page.waitForSelector('genui-data-table');

  // Capture the composed CustomEvent
  const events: any[] = [];
  await page.exposeFunction('__captureEvent', (detail: unknown) => events.push(detail));
  await page.evaluate(() => {
    document.addEventListener('row_selected', (e: Event) =>
      (window as any).__captureEvent((e as CustomEvent).detail),
    { capture: true });
  });

  // Click the second row
  await page.locator('genui-data-table [data-row-id="2"]').click();

  // Assert the event crossed the Shadow boundary
  expect(events).toHaveLength(1);
  expect(events[0]).toEqual({ rowId: '2' });
});
```

## Verification

```bash
# 1. Run the server-half integration test
bun test tests/integration/full-loop.test.ts
# expect: 1 passed, ~400ms

# 2. Run the browser half
bunx playwright test e2e/click-row.spec.ts
# expect: 1 passed, ~3s

# 3. Full suite — proves the loop end-to-end
bun test && bunx playwright test e2e/
# expect: all green; the e2e layer catches what mocks miss (composed:true
# flag, attribute change timing, runtime bridge injection order)
```

If `bun test` fails on `createServer()`, check that you're not running it in parallel with another test that already holds port 3040. The pattern above uses 3041 explicitly; if you have multiple test files, pick a different port per file.

## Pitfalls

- **Don't mock the trust boundary.** The whole point of running the real server is that `stripProtoKeys` + `Value.Check` run on every call. A mocked boundary lets `-32003 props_invalid` through and your tests pass while prod breaks.
- **Use the real `InMemoryStore`, not Jest mocks.** `InMemoryStore` is the source-of-truth for session state during tests — Jest's `jest.fn()` mocks of `Map` miss edge cases (TTL eviction, `on('evicted')` callbacks). See [Core API › `InMemoryStore`](/api/core#inmemorystore).
- **Playwright `exposeFunction` is the right way to capture events.** Don't `console.log` from the page and parse stdout — that breaks when the page is sandboxed or the listener fires before Playwright attaches. Expose a function once and have the page call it.
- **Deterministic test data, not `Date.now()`.** The test pyramid's rule #4 ([Testing › Authoring rules](/guides/testing#authoring-rules)) — pass timestamps as fixtures. A test that asserts `subscription.expiresAt > Date.now()` fails intermittently.
- **Don't share ports across test files.** Bun's parallel runner will race. Pick a unique port per file (3041, 3042, 3043…) or set `GENICUI_PORT=0` and read the bound port from `server.address().port`.
- **Wire-format assertions > frame-content assertions.** Test that `STATE_DELTA` arrived, not that it arrived with exactly the patch ops you expected. The diff engine is allowed to coalesce `replace` ops into `add`/`remove` pairs without breaking the contract.
