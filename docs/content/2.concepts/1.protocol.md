GenicUI carries every interaction as a single-line JSON frame on a WebSocket. Four fields are mandatory (`v`, `channel`, `type`, `payload`) plus a monotonic `seq` counter; reserved channels and AG-UI event names define what the frame *means*. This page is the wire-level reference — the canonical shapes for everything GenicUI emits and accepts.

## What the wire frame looks like

```text
┌──────────────┬───────────────────────────────────────────────────────────┐
│ v            │ Protocol version. Always "1". Frames with v != 1 → 1003. │
├──────────────┼───────────────────────────────────────────────────────────┤
│ channel      │ String, 1-128 chars, no control chars.                   │
│              │  • "__session__" reserved (server.hello, session.*)      │
│              │  • "__mcp__" reserved (TOOL_CALL_*, errors)              │
│              │  • "__agent__" reserved (agent responses)                │
│              │  • "<componentId>" for one mounted component             │
├──────────────┼───────────────────────────────────────────────────────────┤
│ type         │ AG-UI event name (e.g. STATE_DELTA) or GenicUI-specific. │
│              │ Server validates against known event list.               │
├──────────────┼───────────────────────────────────────────────────────────┤
│ payload      │ Schema-conformant JSON object. Shape depends on type.    │
├──────────────┼───────────────────────────────────────────────────────────┤
│ seq          │ uint64 monotonic per channel. Out-of-order frames buffer. │
└──────────────┴───────────────────────────────────────────────────────────┘
```

A complete frame on the wire:

```text
{"v":1,"channel":"dt-sess9f8e-01HK9X","type":"STATE_DELTA","payload":[{"op":"replace","path":"/rows/1/name","value":"updated"}],"seq":42}
```

`Source: packages/core/src/sequence.ts:42` for the canonical `envelope()` helper that builds this shape.

## Why a flat envelope

The envelope stays flat — no nested envelope header — for three reasons:

1. **JSON-line framing.** Every frame is one line of UTF-8 JSON, terminated by `\n`. Line-buffered parsers in Caddy, Cloudflare Workers, and Bun all handle this without a custom decoder.
2. **One channel per frame.** `channel` is a first-class key, so a multiplexer can route a frame to the right subscriber in O(1).
3. **`seq` at the top level.** Reordering and dedupe happen at the channel layer, not deep inside payload schemas.

::callout{type="info"}
The wire frame is also the unit of replay. F33 (Session Recovery) buffers the last 500 frames per channel and replays them by `Last-Event-ID` on reconnect.
::

## The 14 AG-UI events

GenicUI emits a subset of the AG-UI event taxonomy alongside GenicUI-specific events. The 14 events below are the entire surface — there is no other type that crosses the wire.

| # | Event | Emitted by | Payload shape | When |
|---|-------|-----------|---------------|------|
| 1 | `RUN_STARTED` | server | `{ runId }` | First event in an agent turn. |
| 2 | `RUN_FINISHED` | server | `{ runId }` | Last event in an agent turn. |
| 3 | `TOOL_CALL_STARTED` | server | `{ toolCallId, toolName }` | Begins a tool invocation. |
| 4 | `TOOL_CALL_ARGS` | server | `{ toolCallId, args }` | Carries the tool's JSON arguments. |
| 5 | `TOOL_CALL_RESULT` | server | `{ toolCallId, result, isError? }` | Completes the tool invocation. |
| 6 | `STATE_SNAPSHOT` | server | `{ componentId, state }` | Full state — initial mount or patch fallback. |
| 7 | `STATE_DELTA` | server | `{ componentId, patch: JsonPatchOp[] }` | Incremental update via RFC 6902. |
| 8 | `COMPONENT_MOUNTED` | server | `{ componentId, schema, initialState }` | New component goes live. Precedes any `STATE_DELTA`. |
| 9 | `COMPONENT_UNMOUNTED` | server | `{ componentId }` | Component tears down. |
| 10 | `COMPONENT_EVENT` | client→server | `{ componentId, action, detail }` | User-driven action from a mounted component. |
| 11 | `subscription.created` | server | `{ subscriptionId, componentId, events }` | Filter subscription is live. |
| 12 | `subscription.closed` | server | `{ subscriptionId, reason }` | Filter subscription ended (unmount, unsubscribe, error). |
| 13 | `channel.closed` | server | `{ componentId, reason }` | Channel torn down — listeners must drop state. |
| 14 | `server.hello` | server | `{ sessionId, serverVersion, heartbeatMs }` | First frame after WS upgrade. Channel `__session__`. |

::callout{type="warning"}
Server rejects any `type` not in this list with WS code 1003 (unsupported data). Adding a new event type requires updating both the server validator and every client subscriber — keep the list closed.
::

## JSON-RPC framing for tool calls

Tool calls use a thin JSON-RPC 2.0 envelope. The four MCP tools (`find_ui_component`, `render_component`, `update_component`, `subscribe_to_events`) all travel as JSON-RPC requests on the `__mcp__` channel.

::code-group
```json [Request]
{
  "jsonrpc": "2.0",
  "id": "tc-1",
  "method": "render_component",
  "params": {
    "name": "DataTable",
    "props": {
      "rows": [{ "id": "1", "name": "Alice" }],
      "pageSize": 10
    },
    "surface": "default"
  }
}
```

```json [Success]
{
  "jsonrpc": "2.0",
  "id": "tc-1",
  "result": {
    "componentId": "dt-sess9f8e-01HK9X",
    "channel": "dt-sess9f8e-01HK9X",
    "schema": { "...": "..." },
    "events": ["row_selected"]
  }
}
```

```json [Error]
{
  "jsonrpc": "2.0",
  "id": "tc-1",
  "error": {
    "code": -32003,
    "message": "props_invalid",
    "data": { "details": ["required: rows"] }
  }
}
```
::

Error codes occupy the namespace `-32001` through `-32010`. Standard MCP errors (`-32700` parse, `-32600` invalid request, `-32601` method not found, `-32603` internal) are honored but are not GenicUI-specific. The full table lives in [MCP Tools › Error codes](/concepts/mcp-tools#error-codes).

## End-to-end sequence: render a component

```text
┌────────┐                ┌────────┐                ┌────────┐
│ Agent  │                │ Server │                │ Client │
└───┬────┘                └────┬───┘                └────┬───┘
    │  render_component       │                         │
    │ ──────────────────────► │  validate props         │
    │                          │  allocate componentId  │
    │                          │  emit STATE_SNAPSHOT   │
    │                          │ ──────────────────────►│
    │                          │  emit COMPONENT_MOUNTED│
    │                          │ ──────────────────────►│
    │                          │                         │ mount Web Component
    │                          │ ◄──────────────────────│ client.hello (subscribe)
    │                          │                         │
    │  TOOL_CALL_RESULT        │                         │
    │ ◄────────────────────── │                         │
    │                          │                         │
```

Frames flow:

1. **Agent → Server** on `__mcp__`: `TOOL_CALL_STARTED` (seq N), `TOOL_CALL_ARGS` (seq N+1), `TOOL_CALL_RESULT` (seq N+2).
2. **Server → Client** on `<componentId>`: `STATE_SNAPSHOT` (seq 1), `COMPONENT_MOUNTED` (seq 2).
3. **Client → Server** on `<componentId>`: `client.hello` (seq 3) — establishes the reverse subscription.
4. **Server → Agent** on `__agent__`: tool result frame mirroring the JSON-RPC response.

The five events in steps 1 and the two events in step 2 are the AG-UI-required surface for a successful tool call. Skipping any of them breaks client reconnection logic and AG-UI-native consumers (CopilotKit, LangGraph).

## Versioning

The `v` field is the protocol version. Today only `"1"` is defined. Future major versions will increment `v` and ship a parallel subprotocol negotiation. Until then, frames with `v: "1"` are the only valid wire format — anything else closes the socket with WS code 1003.
