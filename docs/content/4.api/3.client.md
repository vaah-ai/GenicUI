The `@genicui/client` package provides the browser-side primitives: a Web Component base class with closed Shadow DOM + JSON-Patch re-rendering, and a runtime engine that wires it to the WebSocket transport. Everything in this package is framework-agnostic — it does not depend on Vue, React, or any UI library.

For the conceptual model, see [Concepts → Components](/concepts/components). For the wire protocol that the runtime engine sends and receives, see [Concepts → Frames](/concepts/frames).

## `GenicElement`

```ts [packages/client/src/index.ts]
export { GenicElement } from './genic-element.js';
```

Web Component base class. Extend it, override `render()` (or `onPatch()` for fine-grained DOM updates), and register with `customElements.define()`. The base class attaches a **closed Shadow DOM**, observes `props-json` and `component-id` attribute changes, applies a JSON-Patch diff on each props change, and forwards composed events to the runtime bridge.

### Class shape

```ts [packages/client/src/genic-element.ts]
export class GenicElement extends HTMLElement {
  static observedAttributes: string[];
  static setRuntimeBridge(bridge: RuntimeBridge): void;
  static getRuntimeBridge(): RuntimeBridge;

  get componentId(): string;
  get props(): GenicElementProps;
  get shadowRoot(): ShadowRoot | null;

  connectedCallback(): void;
  disconnectedCallback(): void;
  attributeChangedCallback(
    name: string,
    oldValue: string | null,
    newValue: string | null,
  ): void;

  protected render(props: GenicElementProps): void;
  protected onPatch(patches: unknown[]): void;
  protected _setupEventForwarding(): void;
}
```

### Static methods

| Method | Description |
| --- | --- |
| `setRuntimeBridge(bridge)` | Inject a concrete `RuntimeBridge` implementation. Call once at application boot — typically by the Runtime Engine on initialization. |
| `getRuntimeBridge()` | Return the currently-injected bridge. Defaults to a no-op stub if not injected. |

### Instance getters

| Getter | Description |
| --- | --- |
| `componentId` | The current `component-id` attribute value. |
| `props` | The current parsed props object (shallow copy). |
| `shadowRoot` | The attached Shadow Root, or `null` if not yet connected. |

### Lifecycle hooks

| Hook | When fired | Behavior |
| --- | --- | --- |
| `connectedCallback()` | Element appended to the DOM | Attaches a closed Shadow DOM, parses initial attributes, calls `render(currentProps)`, and invokes `runtimeBridge.onMount(componentId)`. |
| `disconnectedCallback()` | Element removed from the DOM | Invokes `runtimeBridge.onUnmount(componentId)`. |
| `attributeChangedCallback(name, _old, new)` | `props-json` or `component-id` changes | For `props-json`: applies a JSON-Patch diff and calls `onPatch()`. For `component-id`: updates the stored ID. |

### Methods to override

| Method | Default behavior |
| --- | --- |
| `protected render(props)` | Renders props as a JSON `<pre>` block. **Override** in every concrete subclass. |
| `protected onPatch(patches)` | Re-renders with the current props. **Override** to apply fine-grained DOM updates from the patch operations. |

### Example

```ts [Concrete GenicElement subclass]
import { GenicElement } from '@genicui/client';
import type { GenicElementProps } from '@genicui/client';

class DataTable extends GenicElement {
  protected render(props: GenicElementProps): void {
    if (!this._shadowRoot) return;
    this._shadowRoot.innerHTML = `
      <table>
        ${(props.rows as Array<Record<string, unknown>> ?? [])
          .map((r) => `<tr><td>${r['name']}</td></tr>`)
          .join('')}
      </table>
    `;
  }

  // Optional: handle patches incrementally instead of full re-render
  protected onPatch(patches: unknown[]): void {
    if (!this._shadowRoot) return;
    for (const op of patches as Array<{ op: string; path: string; value?: unknown }>) {
      if (op.op === 'replace' && op.path === '/pageSize') {
        this.querySelector('table')?.setAttribute('data-page-size', String(op.value));
      }
    }
  }
}

customElements.define('genui-data-table', DataTable);
```

::tip
To avoid layout flicker during initial render, set both `component-id` and `props-json` *before* the element is inserted into the DOM (use `document.createElement('genui-data-table')` then `setAttribute(...)` then `appendChild()`).
::

### Observed attributes

```ts [packages/client/src/genic-element.ts]
const OBSERVED_ATTRIBUTES = ['props-json', 'component-id'] as const;
```

| Attribute | Type | Description |
| --- | --- | --- |
| `props-json` | JSON string | The component's current props. Must be valid JSON. |
| `component-id` | string | The unique component ID from the server. Used by the runtime bridge for subscription routing. |

## Runtime engine

The runtime engine wires `GenicElement` to the WebSocket transport. It accepts inbound frames, dispatches `STATE_SNAPSHOT` / `STATE_DELTA` to the right `GenicElement`, emits outbound `COMPONENT_EVENT` frames when children dispatch composed events, and manages the channel-per-component lifecycle.

### `createRuntime(options)` and `RuntimeEngine`

```ts [packages/client/src/runtime/index.ts]
export { createRuntime, RuntimeEngine } from './runtime.js';
export type {
  RuntimeFrameType,
  RuntimeFrame,
  RuntimeOptions,
  MountResult,
  PatchResult,
  ComponentState,
  SnapshotPayload,
  DeltaPayload,
} from './runtime.js';
```

`createRuntime(options)` is the factory; the returned instance is of class `RuntimeEngine`. Use the factory to keep the call sites uniform — both produce an engine you can `.mount()`, `.patch()`, and `.close()`.

### `RuntimeOptions`

```ts [packages/client/src/runtime/types.ts]
interface RuntimeOptions {
  websocketUrl: string;
  channels?: string[];          // channels to subscribe to on connect (default: ['__broadcast__'])
  reconnect?: boolean;          // auto-reconnect on disconnect (default: true)
  maxReconnectDelayMs?: number; // backoff cap (default: 30_000)
  sessionId?: string;           // for Last-Event-ID replay
  bridge?: RuntimeBridge;       // pre-built bridge; one is auto-injected if omitted
}
```

### `RuntimeEngine` methods

| Method | Returns | Description |
| --- | --- | --- |
| `mount(componentId, tag, props)` | `Promise<MountResult>` | Register a `componentId → HTMLElement` binding and subscribe to its channel. |
| `patch(componentId, patches)` | `Promise<PatchResult>` | Apply JSON-Patch to the live props; the engine diffs and dispatches `STATE_DELTA` on the wire. |
| `state(componentId)` | `ComponentState` | Return the current in-memory props + version. |
| `sendEvent(componentId, action, detail)` | `void` | Emit a `COMPONENT_EVENT` frame over WebSocket. |
| `close()` | `Promise<void>` | Disconnect WebSocket, unsubscribe all channels. |

### Types

| Type | Description |
| --- | --- |
| `RuntimeFrame` | `{ type: RuntimeFrameType; channel: string; payload: unknown; seq: number }` — the frame envelope after parsing. |
| `RuntimeFrameType` | String-literal union over the AG-UI events the engine emits / receives. |
| `MountResult` | `{ componentId: string; tagName: string; initialState: Record<string, unknown> }`. |
| `PatchResult` | `{ componentId: string; applied: JsonPatchOperation[]; snapshot: boolean }` — `snapshot: true` indicates the engine fell back to a full snapshot because the patch couldn't be applied. |
| `ComponentState` | `{ props: Record<string, unknown>; version: number; lastSeq: number }`. |
| `SnapshotPayload` | The payload of an inbound `STATE_SNAPSHOT` frame. |
| `DeltaPayload` | The payload of an inbound `STATE_DELTA` frame. |

### Example — connecting a runtime to the GenicElement

```ts [App bootstrap]
import { GenicElement, createRuntime } from '@genicui/client';
import type { RuntimeBridge } from '@genicui/client';

const runtime = await createRuntime({
  websocketUrl: 'ws://localhost:3040/ws',
  channels: ['__broadcast__'],
  reconnect: true,
});

// Inject the runtime's bridge into every GenicElement
GenicElement.setRuntimeBridge(runtime.bridge());

// Inbound STATE_SNAPSHOT frame → runtime calls element.setAttribute('props-json', ...)
runtime.on('STATE_SNAPSHOT', ({ componentId, payload }) => {
  const el = document.querySelector<GenicElement>(
    `[component-id="${componentId}"]`,
  );
  el?.setAttribute('props-json', JSON.stringify(payload.state));
});
```

## `RuntimeBridge` interface

```ts [packages/client/src/types.ts]
export interface RuntimeBridge extends RuntimeBridgeCallbacks {
  onMount(componentId: string): void;
  onUnmount(componentId: string): void;
  onEvent(componentId: string, payload: ComponentEventPayload): void;
}

export interface RuntimeBridgeCallbacks {
  onMount?(componentId: string): void;
  onUnmount?(componentId: string): void;
  onEvent?(componentId: string, payload: ComponentEventPayload): void;
}

export interface ComponentEventPayload {
  action: string;
  detail: Record<string, unknown>;
}
```

The bridge is the seam between `GenicElement` and the runtime engine. The base class calls `onMount`, `onUnmount`, and `onEvent`; the runtime engine implements those methods to drive the WebSocket transport.

The interface exists to break the circular dependency between `GenicElement` (F21) and `RuntimeEngine` (F29): the base class is implemented in terms of the bridge, the engine is implemented in terms of the base class. Injection via `setRuntimeBridge()` resolves the cycle at app boot.

## Types — `GenicElementProps`

```ts [packages/client/src/types.ts]
export interface GenicElementProps {
  readonly [key: string]: unknown;
}
```

The props shape passed to `render()`. Indexable by string; concrete components should narrow with a schema (see [Core API → genicSchema](/api/core#genicschemadefinition)).

::note
**No Vue subpath exists.** Earlier design notes referenced `@genicui/client/vue` with `useGenicComponent`, `<GenicProvider>`, and a `v-genic` directive. That subpath is not shipped. If you need Vue convenience helpers, build them on top of `GenicElement.setRuntimeBridge()` and `createRuntime()` — the [Guides → Development](/guides/development) page walks through the Vue integration using `examples/playground/`.
::
