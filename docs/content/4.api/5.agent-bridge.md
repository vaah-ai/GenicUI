`@genicui/agent-bridge` is the platform-agnostic glue between any LLM provider (OpenAI, Anthropic, OpenAI-compatible) and the GenicUI MCP tool surface. Connect to an MCP endpoint, hand the bridge an LLM config, and it routes the model's tool calls through the server's `find_ui_component` / `render_component` / `update_component` / `subscribe_to_events` surface.

For the lifecycle model and a full walkthrough, see [Concepts → MCP Tools](/concepts/mcp-tools#the-agent-bridge-loop).

## `AgentBridge`

```ts [packages/agent-bridge/src/index.ts]
export { AgentBridge } from './agent-bridge.js';
```

Top-level orchestrator. Wraps an `LLMProvider` and an `MCPClient` and drives the agent loop: call LLM → execute tool calls → feed results back → repeat until the LLM returns a text response.

### Static factory

```ts [packages/agent-bridge/src/agent-bridge.ts]
static async connect(
  llmConfig: LLMProviderConfig,
  mcpEndpoint: string,
  options?: AgentBridgeOptions,
): Promise<AgentBridge>
```

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `llmConfig` | `LLMProviderConfig` | yes | Provider, API key, model, optional `baseUrl` / `timeoutMs` / `headers`. |
| `mcpEndpoint` | `string` | yes | MCP Streamable HTTP URL (e.g., `'http://localhost:3040/mcp'`). |
| `options.maxToolChain` | `number` | no | Maximum agent-loop iterations before bailing. Default `10`. |
| `options.systemPrompt` | `string` | no | Override the auto-built system prompt. If omitted, `buildSystemPrompt()` is called with the discovered tools. |

**Returns:** `Promise<AgentBridge>` — connected and ready to `.execute(prompt)`.

### Instance methods

| Method | Returns | Description |
| --- | --- | --- |
| `execute(prompt)` | `Promise<string>` | Drive the agent loop until the LLM returns text. Each iteration: chat → tool calls → results → chat. |
| `getTools()` | `MCPToolDefinition[]` | Snapshot of the tools fetched from the MCP server during `connect()`. |
| `close()` | `Promise<void>` | Disconnect the MCP client and release resources. |

### Example

```ts [Full agent-bridge loop]
import { AgentBridge } from '@genicui/agent-bridge';

const bridge = await AgentBridge.connect(
  {
    provider: 'anthropic',
    apiKey: process.env.ANTHROPIC_API_KEY!,
    model: 'claude-sonnet-4-20250514',
  },
  'http://localhost:3040/mcp',
  { maxToolChain: 8 },
);

try {
  const reply = await bridge.execute('Show me a data table with orders');
  console.log(reply);
} finally {
  await bridge.close();
}
```

## `AgentBridgeError`

```ts [packages/agent-bridge/src/index.ts]
export { AgentBridgeError, createLLMProvider } from './llm-provider.js';
```

```ts [packages/agent-bridge/src/llm-provider.ts]
export class AgentBridgeError extends Error {
  readonly provider: string;
  constructor(provider: string, message: string);
}
```

Thrown by `LLMProvider` implementations when the underlying API call fails (HTTP non-2xx, malformed response, missing choices/content). The `provider` field identifies which provider produced the error.

```ts
import { AgentBridgeError } from '@genicui/agent-bridge';

try {
  await bridge.execute(prompt);
} catch (err) {
  if (err instanceof AgentBridgeError) {
    console.error(`${err.provider}: ${err.message}`);
  }
  throw err;
}
```

## `createLLMProvider(config)`

```ts [packages/agent-bridge/src/index.ts]
export { AgentBridgeError, createLLMProvider } from './llm-provider.js';
```

Factory that returns an `LLMProvider` implementation matching `config.provider`. The two built-in providers are `OpenAIProvider` and `AnthropicProvider`; both are fetch-based — no provider SDK is required at runtime.

```ts [packages/agent-bridge/src/llm-provider.ts]
function createLLMProvider(config: LLMProviderConfig): LLMProvider
```

### Provider matrix

| `config.provider` | Adapter | Default `baseUrl` | Notes |
| --- | --- | --- | --- |
| `'openai'` | `OpenAIProvider` | `https://api.openai.com` | OpenAI function-calling format. |
| `'openai-compatible'` | `OpenAIProvider` | `https://api.openai.com` | Override `baseUrl` for Groq, Together, Ollama, etc. |
| `'anthropic'` | `AnthropicProvider` | `https://api.anthropic.com` | Anthropic `tool_use` block format. `max_tokens` is fixed at `8192` (overridable by extending `AnthropicProvider`). |

### `LLMProviderConfig`

```ts [packages/agent-bridge/src/types.ts]
interface LLMProviderConfig {
  provider: ProviderType;       // 'openai' | 'anthropic' | 'openai-compatible'
  apiKey: string;
  model: string;                 // e.g., 'gpt-4o', 'claude-sonnet-4-20250514'
  baseUrl?: string;              // override for self-hosted / openai-compatible
  timeoutMs?: number;            // default 30_000
  headers?: Record<string, string>;  // extra request headers
}

type ProviderType = 'openai' | 'anthropic' | 'openai-compatible';
```

### Example — OpenAI-compatible (Groq)

```ts
import { createLLMProvider } from '@genicui/agent-bridge';

const provider = createLLMProvider({
  provider: 'openai-compatible',
  apiKey: process.env.GROQ_API_KEY!,
  model: 'llama-3.1-70b-versatile',
  baseUrl: 'https://api.groq.com/openai',
});

const response = await provider.chat(messages, tools);
```

## `MCPClientImpl`

```ts [packages/agent-bridge/src/index.ts]
export { MCPClientImpl } from './mcp-client.js';
```

Fetch-based MCP Streamable HTTP client. Performs the MCP `initialize` handshake on `connect()`, then exposes `listTools()` and `callTool()`. No `@modelcontextprotocol/client` dependency required — the wire format is just JSON-RPC over HTTP POST.

### Methods

| Method | Returns | Description |
| --- | --- | --- |
| `connect(url)` | `Promise<void>` | Send `initialize`, fire the `initialized` notification, mark the client ready. |
| `listTools()` | `Promise<MCPToolDefinition[]>` | Issue `tools/list`; parse the response into `{ name, description, inputSchema }`. |
| `callTool(name, args)` | `Promise<string>` | Issue `tools/call`; return the joined `text` content. Throws if `result.isError` is `true`. |
| `close()` | `Promise<void>` | Reset internal state. No persistent connection to close (HTTP is request-scoped). |

### Example — using MCPClientImpl directly

```ts
import { MCPClientImpl } from '@genicui/agent-bridge';

const client = new MCPClientImpl();
await client.connect('http://localhost:3040/mcp');

const tools = await client.listTools();
const result = await client.callTool('find_ui_component', { query: 'table' });
console.log(JSON.parse(result));

await client.close();
```

### `MCPToolDefinition`

```ts [packages/agent-bridge/src/types.ts]
interface MCPToolDefinition {
  name: string;
  description: string;
  inputSchema: unknown;     // JSON Schema for the tool's `arguments`
}
```

## `buildSystemPrompt(tools)`

```ts [packages/agent-bridge/src/index.ts]
export { buildSystemPrompt } from './prompt-builder.js';
```

Generates the default system prompt passed to the LLM. Lists every discovered tool, explains the four-step GenicUI lifecycle (`find → render → update → subscribe`), and adds behavioral guidelines.

| Parameter | Type | Description |
| --- | --- | --- |
| `tools` | `MCPToolDefinition[]` | The tools the bridge should mention. Typically the value of `AgentBridge.getTools()`. |

**Returns:** `string` — the prompt body. Pass it to `AgentBridge.connect({ ... }, { systemPrompt })` to override the auto-built prompt.

```ts [packages/agent-bridge/src/prompt-builder.ts]
function buildSystemPrompt(tools: MCPToolDefinition[]): string
```

**Example — customizing the prompt**

```ts
import { AgentBridge, buildSystemPrompt } from '@genicui/agent-bridge';

const bridge = await AgentBridge.connect(
  { provider: 'openai', apiKey: 'sk-...', model: 'gpt-4o' },
  'http://localhost:3040/mcp',
  {
    systemPrompt: `${buildSystemPrompt(tools)}\n\nAdditional rule: always include a fallback text answer alongside any render_component call.`,
  },
);
```

The resulting prompt begins:

```
You are a GenicUI agent that can render interactive UI components for the user.

## Available Tools
- **find_ui_component**: Search the component catalog ...
- **render_component**: Mount a component on the client ...

## How to Use Tools
1. find_ui_component — Search the component catalog ...
...
```

## Full end-to-end example

```ts [app.ts]
import { AgentBridge, AgentBridgeError, MCPClientImpl } from '@genicui/agent-bridge';

async function main() {
  const bridge = await AgentBridge.connect(
    {
      provider: 'openai',
      apiKey: process.env.OPENAI_API_KEY!,
      model: 'gpt-4o',
    },
    'http://localhost:3040/mcp',
    { maxToolChain: 12 },
  );

  bridge.execute('What is the weather in Paris?').then(console.log).catch((err) => {
    if (err instanceof AgentBridgeError) {
      console.error(`LLM provider ${err.provider} failed: ${err.message}`);
      process.exit(1);
    }
    throw err;
  });

  // Inspect what tools the MCP server advertised:
  console.log('Tools:', bridge.getTools().map((t) => t.name));

  await bridge.close();
}

main();
```

::tip
The bridge performs tool calls *server-side* via MCP — your application never needs to import `@modelcontextprotocol/*` packages. The bridge speaks JSON-RPC over HTTP and forwards everything to the GenicUI server.
::
