The `@genicui/core` package contains the framework-agnostic primitives that every other package depends on. It has no DOM, no Node-specific globals, and no transport — the runtime-agnostic source of truth for schemas, JSON-Patch, sequence generation, and the AG-UI wire envelope.

For the conceptual model behind each export, see [Concepts → Components](/concepts/components) and [Concepts → Frames](/concepts/frames). This page is the reference — terse, table-heavy, verbatim from `packages/core/src/`.

## Constants

### `VERSION`

```ts [packages/core/src/index.ts]
export const VERSION: string = "0.1.0";
```

Package version. Updated automatically by release tooling. The only top-level export that is not re-exported from a submodule.

## Schema builder

A small wrapper around JSON Schema 2020-12 that adds fluent composition, defaults, and a single-call validator. See [Concepts → Components](/concepts/components#schemas) for the rationale.

### `genicSchema(definition)`

```ts [packages/core/src/index.ts]
export { genicSchema, createGenicSchema } from './schema/genic-schema.js';
```

Create a schema from a JSON Schema 2020-12 definition. The returned object bundles the schema, an optional validator, and a helper for merging defaults.

| Parameter | Type | Description |
| --- | --- | --- |
| `definition` | `JSONSchema2020_12` | A JSON Schema 2020-12 document describing the shape. |

**Returns:** `GenicSchemaResult` — `{ schema, validate, defaults }`.

**Example**

```ts
import { genicSchema } from '@genicui/core';

const UserSchema = genicSchema({
  type: 'object',
  required: ['id', 'email'],
  properties: {
    id: { type: 'string' },
    email: { type: 'string', format: 'email' },
    age: { type: 'integer', minimum: 0, default: 18 },
  },
  additionalProperties: false,
});

UserSchema.validate({ id: '1', email: 'a@b.c', age: 30 }); // ok
UserSchema.validate({ id: '1', email: 'a@b.c' });          // ok (default age applied)
UserSchema.validate({ id: '1' });                           // { valid: false, errors: ['/email: required'] }
```

### `createGenicSchema(builder)`

```ts [packages/core/src/index.ts]
export { genicSchema, createGenicSchema } from './schema/genic-schema.js';
```

Fluent builder variant. Useful when the schema shape is computed at runtime.

| Parameter | Type | Description |
| --- | --- | --- |
| `builder` | `GenicSchemaBuilder` | A builder closure that calls `.field()`, `.required()`, `.additionalProperties(false)`, etc. |

**Returns:** `GenicSchemaResult`.

**Example**

```ts
import { createGenicSchema } from '@genicui/core';

const OrderSchema = createGenicSchema((b) =>
  b
    .field('id', { type: 'string' })
    .field('total', { type: 'number', minimum: 0 })
    .required(['id', 'total'])
    .additionalProperties(false),
);
```

## Protocol — AG-UI frame envelope

Single-line JSON envelope used by every WebSocket frame. See [Concepts → Frames](/concepts/frames) for the wire model.

### `SequenceGenerator`

```ts [packages/core/src/index.ts]
export { SequenceGenerator } from './protocol/index.js';
```

Monotonic uint64 sequence number generator. A single instance is shared per WebSocket transport. Each call to `.next()` returns the next number and advances the counter.

```ts
import { SequenceGenerator } from '@genicui/core';

const seq = new SequenceGenerator();
seq.next(); // 1
seq.next(); // 2
```

### `envelope(type, payload, channel, options?)`

```ts [packages/core/src/index.ts]
export { envelope } from './protocol/index.js';
```

Build a single-line JSON frame envelope. Validates the payload against the TypeBox schema for `type` and rejects reserved channels before serializing.

| Parameter | Type | Description |
| --- | --- | --- |
| `type` | `AGUIEventType` | One of the 14 AG-UI event types (see `AG_UI_EVENT_TYPES`). |
| `payload` | `Record<string, unknown>` | The event payload — validated against the schema for `type`. |
| `channel` | `string` | Channel name. Must not equal any `RESERVED_CHANNELS` entry. |
| `options.seq` | `number \| undefined` | Override the sequence number. Defaults to `SequenceGenerator.next()`. |
| `options.causes` | `string[] \| undefined` | Causality chain — previous frame `seq` values. |

**Returns:** `FrameEnvelope`.

**Throws:** `GenicUIError` if `channel` is reserved or `payload` fails schema validation.

**Example**

```ts
import { envelope, SequenceGenerator } from '@genicui/core';

const seq = new SequenceGenerator();

const frame = envelope(
  'STATE_SNAPSHOT',
  { componentId: 'dt-1', state: { rows: [] } },
  'dt-1',
  { seq: seq.next() },
);
// → { v: 1, channel: 'dt-1', type: 'STATE_SNAPSHOT', payload: {...}, seq: 1 }
```

### `validateChannel(channel)`

```ts [packages/core/src/index.ts]
export { validateChannel } from './protocol/index.js';
```

Throw `GenicUIError` if `channel` matches a reserved channel name (`__system__`, `__broadcast__`, …) or exceeds `MAX_CHANNELS_PER_SOCKET` per socket.

```ts
import { validateChannel } from '@genicui/core';

validateChannel('dt-1');           // ok
validateChannel('__system__');     // throws GenicUIError (RESERVED)
```

### `FrameBuffer`

```ts [packages/core/src/index.ts]
export { FrameBuffer } from './protocol/index.js';
```

In-memory ring buffer of recent frames per socket. The runtime writes each frame it sends; the session-recovery layer reads from it on `Last-Event-ID` replay. Default capacity is `MAX_CHANNELS_PER_SOCKET`; older frames are evicted by `seq`.

```ts
import { FrameBuffer } from '@genicui/core';

const buffer = new FrameBuffer({ capacity: 256 });
buffer.push(frame);
buffer.since(lastEventId); // → FrameBufferResult (all frames with seq > lastEventId)
```

### `FrameEnvelopeSchema`

```ts [packages/core/src/index.ts]
export { FrameEnvelopeSchema } from './protocol/index.js';
```

TypeBox schema for the `FrameEnvelope` shape. Use it when validating externally produced frames (e.g., from a test fixture or a custom transport).

```ts
import { FrameEnvelopeSchema } from '@genicui/core';

const result = FrameEnvelopeSchema.Check(JSON.parse(line));
```

## JSON-Patch engine

Thin, immutable wrapper around [fast-json-patch](https://github.com/Starcounter-JS/JSON-Patch). See [Concepts → Frames](/concepts/frames#state-delta) for the wire use.

### `JsonPatchEngine`

```ts [packages/core/src/index.ts]
export { JsonPatchEngine } from './patch/index.js';
```

Apply and diff RFC 6902 patches. Defaults to `{ mutate: false }` — every operation returns a new object; the input is never mutated.

```ts
import { JsonPatchEngine } from '@genicui/core';

const engine = new JsonPatchEngine();

// Diff
const patch = engine.diff({ a: 1 }, { a: 2 });
// → [{ op: 'replace', path: '/a', value: 2 }]

// Apply
const next = engine.apply(patch, { a: 1 });
// → { a: 2 }   (input unchanged)
```

### `JsonPatchOperation` (type)

```ts [packages/core/src/index.ts]
export type { JsonPatchOperation } from './patch/index.js';
```

The RFC 6902 op union: `'add' | 'remove' | 'replace' | 'move' | 'copy' | 'test'`.

### `NonSerializableError`, `hasNonSerializable`, `findNonSerializableType`

```ts [packages/core/src/index.ts]
export {
  JsonPatchEngine,
  NonSerializableError,
  hasNonSerializable,
  findNonSerializableType,
} from './patch/index.js';
```

Helpers for catching non-serializable values (`undefined`, functions, symbols, circular refs) before they reach the wire. Used internally by `envelope()` and exported for downstream callers.

```ts
import { hasNonSerializable, findNonSerializableType } from '@genicui/core';

hasNonSerializable({ a: 1 });            // false
hasNonSerializable({ a: undefined });     // true
findNonSerializableType({ a: () => 1 }); // 'function'
```

## SessionStore

Interface for session-scoped state, with a default in-memory implementation.

### `InMemoryStore`

```ts [packages/core/src/index.ts]
export { InMemoryStore } from './session/index.js';
```

`Map`-backed implementation of [`SessionStore`](#sessionstore-interface). Suitable for single-process development; production deployments should swap in a Durable Object–backed implementation.

```ts
import { InMemoryStore } from '@genicui/core';

const sessions = new InMemoryStore<string, { userId: string }>();
sessions.set('sess-1', { userId: 'u-1' });
sessions.get('sess-1');   // { userId: 'u-1' }
sessions.delete('sess-1');
sessions.on('evicted', (id) => console.log('evicted', id));
```

### `SessionStore` interface

```ts [packages/core/src/index.ts]
export type { SessionStore, SessionStoreCallback } from './session/index.js';
```

```ts [packages/core/src/session/index.ts]
interface SessionStore<K, V> {
  get(key: K): V | undefined;
  set(key: K, value: V): void;
  delete(key: K): boolean;
  has(key: K): boolean;
  size(): number;
  on(event: 'evicted', cb: SessionStoreCallback<K>): void;
  off(event: 'evicted', cb: SessionStoreCallback<K>): void;
}

type SessionStoreCallback<K> = (key: K) => void;
```

The interface is intentionally tiny — implementations are free to add TTL, persistence, and replication.

::note
The `M5.1-T8` task spec also lists `genuiSessionStore` as an export. That export does not exist in the current `packages/core/src/index.ts` — only `InMemoryStore` and the `SessionStore` interface are exported. Do not import a `genuiSessionStore` symbol; it does not exist.
::
