`@genicui/server` exposes a **single TypeScript export** — `createServer()` — and an **MCP tool JSON-RPC surface** that is the *real* API. Documenting only the TS export would mislead you: every consumer of the server talks to the four MCP tools over HTTP, not to `createServer()` directly.

This page covers both surfaces. For the conceptual model behind each tool, see [Concepts → MCP Tools](/concepts/mcp-tools). For the wire envelope, see [Concepts → Frames](/concepts/frames).

## createServer()

```ts [packages/server/src/index.ts]
export function createServer(): import('elysia').Elysia
```

Boot the HTTP + WebSocket server. Returns the configured Elysia app (useful for test harnesses that want to `.handle()` requests without binding a port). When called as the module entry point (`bun packages/server/bin/start.ts` or via `start.sh`), the server binds and listens.

| Behavior | Reference |
| --- | --- |
| Default port | `3040` (override via `GENICUI_PORT`) |
| Default hostname | `0.0.0.0` (override via `GENICUI_HOSTNAME`) |
| Health route | `GET /health` → `{ status: 'ok' }` |
| WebSocket route | `GET /ws` (subprotocol + API-key auth) |
| MCP route | `POST /mcp` (streamable JSON-RPC) |
| Authenticated routes | `GET /api/status`, `GET /api/registries` |
| Registry loading | `GENICUI_REGISTRIES_DIR` env var (F43) |
| API-key loading | `GENICUI_API_KEY` env var (F46) |

**Example — programmatic boot**

```ts [start.sh equivalent]
import { createServer } from '@genicui/server';

const app = createServer();
// Elysia is now listening on http://0.0.0.0:3040
```

::note
The runtime entry point is `packages/server/bin/start.ts` (production launcher) or `start.sh` at the repo root. `createServer()` is what both call — see the [Server boot sequence](/concepts/mcp-tools#the-server-boot-sequence) concept page.
::

## MCP tool surface

The four MCP tools share a common request envelope. Every `tools/call` is a JSON-RPC 2.0 message:

```json [tools/call envelope]
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "tools/call",
  "params": {
    "name": "<tool-name>",
    "arguments": { /* tool-specific */ }
  }
}
```

A successful response carries the tool result under `result.content[0].text`; an error response uses the standard JSON-RPC error envelope with a GenicUI-specific code (see [Error codes](#error-codes)).

### `find_ui_component`

Search the component catalog for UI components matching a query. Used by agents to *discover* what they can render before calling `render_component`.

**Input schema (Zod — MCP surface)**

```ts [packages/server/src/mcp/tool-registry.ts]
const FindUiComponentInputSchema = z.object({
  query: z.string().min(1).max(512),
  topK: z.number().int().min(1).max(100).optional().default(5),
});
```

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | `string` (1–512 chars) | yes | Free-text search query (component name, tags, description). |
| `topK` | `integer` (1–100) | no (default `5`) | Maximum results to return. |

**Output shape** (returned as `result.content[0].text` JSON):

```ts [packages/server/src/mcp/catalog.ts]
interface FindResult {
  components: Array<{
    name: string;
    version: string;
    registryId: string;
    description: string;
    whenToUse: string;
    propsSchema: Record<string, unknown>;
    events: string[];
    examples: Array<Record<string, unknown>>;
    score: number;
  }>;
  reason?: 'no_component_matches';
  disambiguation?: string[];
}
```

**Example request**

```json [MCP POST /mcp]
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "tools/call",
  "params": {
    "name": "find_ui_component",
    "arguments": { "query": "table", "topK": 3 }
  }
}
```

**Example response**

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{\n  \"components\": [\n    {\n      \"name\": \"DataTable\",\n      \"version\": \"0.1.0\",\n      \"registryId\": \"primevue@4.2.0\",\n      \"description\": \"Display tabular data with sorting, pagination, and row selection.\",\n      \"score\": 0.92\n    }\n  ]\n}"
      }
    ]
  }
}
```

**Error codes that may be returned** — none from this tool; validation failures on `query` / `topK` are returned as standard JSON-RPC `-32602` invalid params.

### `render_component`

Mount a component on the connected client. Returns a `componentId` for subsequent `update_component` and `subscribe_to_events` calls.

**Input schema (Zod — MCP surface)**

```ts [packages/server/src/mcp/tool-registry.ts]
const RenderComponentInputSchema = z.object({
  name: z.string().min(1).max(128),
  props: z.record(z.string(), z.unknown()),
  surface: z.string().optional(),
  idempotencyKey: z.string().optional(),
  parentComponentId: z.string().optional(),
  replaceComponentId: z.string().optional(),
  transition: z.record(z.string(), z.unknown()).optional(),
  render_mode: z.enum(['inline', 'iframe']).optional(),
});
```

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | `string` (1–128 chars) | yes | Component name (e.g., `DataTable`). Must not be a catalog URI like `ui://catalog/primevue/data-table`. |
| `props` | `Record<string, unknown>` | yes | Component props — validated against the catalog `propsSchema`. |
| `surface` | `string` | no | Target rendering surface identifier. |
| `idempotencyKey` | `string` | no | Replay safety — same key returns the same `componentId`. |
| `parentComponentId` | `string` | no | Mount as a child of an existing component. |
| `replaceComponentId` | `string` | no | Replace the props/state of an already-mounted component. |
| `transition` | `Record<string, unknown>` | no | Transition animation configuration. |
| `render_mode` | `'inline' \| 'iframe'` | no | Render mode. |

**Output shape**

```ts [packages/server/src/mcp/render-handler.ts]
interface RenderResult {
  componentId: string;
  channel: string;
  name: string;
  schema: Record<string, unknown>;
  events: readonly string[];
  initialState: Record<string, unknown>;
}
```

**Example request**

```json [MCP POST /mcp]
{
  "jsonrpc": "2.0",
  "id": "2",
  "method": "tools/call",
  "params": {
    "name": "render_component",
    "arguments": {
      "name": "DataTable",
      "props": {
        "rows": [
          { "id": "1", "name": "Alice" },
          { "id": "2", "name": "Bob" }
        ],
        "columns": [{ "key": "name", "label": "Name" }],
        "pageSize": 10
      },
      "idempotencyKey": "orders-table-q3"
    }
  }
}
```

**Example response**

```json
{
  "jsonrpc": "2.0",
  "id": "2",
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{\n  \"componentId\": \"dt-7f3a9b2c-01HXYZABCDEFGHJKMNPQRST\",\n  \"channel\": \"dt-7f3a9b2c-01HXYZABCDEFGHJKMNPQRST\",\n  \"schema\": { \"type\": \"object\", \"additionalProperties\": false, ... },\n  \"events\": [\"row_selected\", \"sort_change\", \"page_change\", \"filter_change\"],\n  \"initialState\": { \"rows\": [...], \"columns\": [...], \"pageSize\": 10 }\n}"
      }
    ]
  }
}
```

**Error codes that may be returned**

| Code | Meaning |
| --- | --- |
| `-32002 invalid_resource_uri` | `name` is a catalog URI (e.g. `ui://catalog/primevue/data-table`). Pass the bare component name instead. |
| `-32001 component_not_found` | The component name does not match any catalog entry. |
| `-32003 props_invalid` | `props` fails the catalog `propsSchema` validation; `error.details` lists the JSON-Pointer paths. |

### `update_component`

Mutate the state of a mounted component. Two modes — `patch` (JSON-Patch primary) and `merge` (shallow merge fallback) — never both.

**Input schema (Zod — MCP surface)**

```ts [packages/server/src/mcp/tool-registry.ts]
const UpdateComponentInputSchema = z.union([
  z.object({
    componentId: z.string().min(1).max(128),
    patch: z.array(JsonPatchOperationSchema).min(1),
  }),
  z.object({
    componentId: z.string().min(1).max(128),
    merge: z.record(z.string(), z.unknown()),
  }),
]);
```

**Patch mode (RFC 6902)**

```ts [packages/server/src/mcp/tool-registry.ts]
const JsonPatchOperationSchema = z.union([
  z.object({ op: z.enum(['add', 'replace', 'test']), path: z.string(), value: z.unknown() }),
  z.object({ op: z.literal('remove'), path: z.string() }),
  z.object({ op: z.enum(['move', 'copy']), from: z.string(), path: z.string() }),
]);
```

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `componentId` | `string` (1–128 chars) | yes | Mounted component ID returned by `render_component`. |
| `patch` | `JsonPatchOperation[]` (≥1) | yes (patch mode) | RFC 6902 operations. |
| `merge` | `Record<string, unknown>` | yes (merge mode) | Shallow merge into the current props. |

**Output shape**

```ts [packages/server/src/mcp/update-handler.ts]
type UpdateResult =
  | {
      componentId: string;
      channel: string;
      type: 'STATE_DELTA';
      patch: JsonPatchOperation[];
    }
  | {
      componentId: string;
      channel: string;
      type: 'STATE_SNAPSHOT';
      snapshot: Record<string, unknown>;
    };
```

`STATE_DELTA` is returned on successful patch application. `STATE_SNAPSHOT` is returned when (a) merge mode is used, or (b) patch application throws and the runtime falls back to a full snapshot to avoid torn state.

**Example request — patch mode**

```json [MCP POST /mcp]
{
  "jsonrpc": "2.0",
  "id": "3",
  "method": "tools/call",
  "params": {
    "name": "update_component",
    "arguments": {
      "componentId": "dt-7f3a9b2c-01HXYZABCDEFGHJKMNPQRST",
      "patch": [
        { "op": "replace", "path": "/pageSize", "value": 25 },
        { "op": "add", "path": "/rows/-", "value": { "id": "3", "name": "Carol" } }
      ]
    }
  }
}
```

**Example request — merge mode**

```json
{
  "jsonrpc": "2.0",
  "id": "3b",
  "method": "tools/call",
  "params": {
    "name": "update_component",
    "arguments": {
      "componentId": "dt-7f3a9b2c-01HXYZABCDEFGHJKMNPQRST",
      "merge": { "loading": true, "filters": { "status": "active" } }
    }
  }
}
```

**Error codes that may be returned**

| Code | Meaning |
| --- | --- |
| `-32001 component_not_found` | `componentId` does not match any mounted component. |
| `-32004 patch_invalid` | A patch path doesn't resolve in the current props (F17-AC5). |
| `-32003 props_invalid` | Both `patch` and `merge` were provided, or post-merge state fails schema validation. |

::tip
Concurrent updates on the same `componentId` are serialized via the `ComponentStore`'s per-componentId locks (F17-AC4). You do not need to coordinate calls.
::

### `subscribe_to_events`

Listen for events emitted by a mounted component. Returns a `subscriptionId` that can later be passed to `unsubscribe` (server-internal) or used to filter an outbound SSE/WS stream.

**Input schema (Zod — MCP surface)**

```ts [packages/server/src/mcp/tool-registry.ts]
const SubscribeToEventsInputSchema = z.object({
  componentId: z.string().min(1).max(128).optional(),
  actions: z.array(z.string().min(1)).min(1).optional(),
  sessionId: z.string().min(1).max(128).optional(),
  expiresAt: z.string().datetime().optional(),
});
```

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `componentId` | `string` (1–128 chars) | no | Filter — only events from this component. |
| `actions` | `string[]` (≥1) | no | Filter — only these action names (e.g., `["row_selected"]`). |
| `sessionId` | `string` (1–128 chars) | no | Scope the subscription to a session. |
| `expiresAt` | `string` (ISO 8601) | no | Expiration timestamp. Defaults to **1 hour** from creation. |

**Output shape**

```ts [packages/server/src/mcp/subscribe-handler.ts]
interface SubscribeResult {
  subscriptionId: string;        // "sub-9c2a1f"
  componentId: string | undefined;
  actions: readonly string[] | undefined;
}
```

**Example request**

```json [MCP POST /mcp]
{
  "jsonrpc": "2.0",
  "id": "4",
  "method": "tools/call",
  "params": {
    "name": "subscribe_to_events",
    "arguments": {
      "componentId": "dt-7f3a9b2c-01HXYZABCDEFGHJKMNPQRST",
      "actions": ["row_selected"],
      "expiresAt": "2026-09-10T18:30:00Z"
    }
  }
}
```

**Example response**

```json
{
  "jsonrpc": "2.0",
  "id": "4",
  "result": {
    "content": [
      { "type": "text", "text": "{\n  \"subscriptionId\": \"sub-9c2a1f\",\n  \"componentId\": \"dt-7f3a9b2c-01HXYZABCDEFGHJKMNPQRST\",\n  \"actions\": [\"row_selected\"]\n}" }
    ]
  }
}
```

**Error codes that may be returned** — none from this tool; validation failures on `expiresAt` (must be ISO 8601) are returned as standard JSON-RPC `-32602`.

::note
The `EventSubscriptionManager` auto-cleans subscriptions when the underlying component is unmounted (F18-AC3). You do not need to call unsubscribe on component unmount.
::

## Error codes

GenicUI reserves the JSON-RPC error code range `-32001..-32010` for server-defined errors. The full set is exported as `GENICUI_ERROR_CODES` from `packages/server/src/mcp/tool-registry.ts`.

```ts [packages/server/src/mcp/tool-registry.ts]
export const GENICUI_ERROR_CODES = {
  component_not_found:    -32001,
  component_already_mounted: -32002,
  invalid_resource_uri:   -32002,
  props_invalid:          -32003,
  patch_invalid:          -32004,
  rate_limited:           -32005,
  quota_exceeded:         -32006,
  auth_invalid:           -32007,
  surface_unavailable:    -32008,
  region_mismatch:        -32009,
  internal:               -32010,
} as const;
```

| Code | Constant | Meaning | Tools that return it |
| --- | --- | --- | --- |
| `-32001` | `component_not_found` | The component name (or `componentId`) does not exist in the catalog / mounted store. | `render_component`, `update_component` |
| `-32002` | `component_already_mounted` / `invalid_resource_uri` | Two meanings share this code: an idempotency-key collision, or a catalog URI passed where an instance URI / bare name is expected. | `render_component` |
| `-32003` | `props_invalid` | Provided props fail the catalog `propsSchema` validation, or both `patch` and `merge` were supplied to `update_component`. | `render_component`, `update_component` |
| `-32004` | `patch_invalid` | A JSON-Patch operation references a path that does not exist in the current props. | `update_component` |
| `-32005` | `rate_limited` | Caller exceeded the per-second request limit. | all tools |
| `-32006` | `quota_exceeded` | API-key daily or monthly quota exhausted. | all tools |
| `-32007` | `auth_invalid` | Missing or invalid API key, or wrong key type for the environment (test vs. live). | all `/api/*` + `/ws` |
| `-32008` | `surface_unavailable` | The requested render surface is offline (e.g., a Durable Object region is down). | `render_component` |
| `-32009` | `region_mismatch` | Request was routed to a non-home region for this API key (Cloudflare Durable Objects). | all tools |
| `-32010` | `internal` | Unhandled server error — see `error.message` for the underlying cause. | all tools |

When any of the above is returned, the JSON-RPC error envelope is:

```json [Error envelope]
{
  "jsonrpc": "2.0",
  "id": "3",
  "error": {
    "code": -32003,
    "message": "Invalid props for component \"DataTable\": /rows: must be array; /columns/0/label: required",
    "data": { "details": ["/rows: must be array", "/columns/0/label: required"] }
  }
}
```

For tool-level errors, the error is returned under `result.content[0].text` with `result.isError = true` and the `[code]` prefix in the message — see the per-tool examples above.
